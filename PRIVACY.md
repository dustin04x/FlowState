# Privacy policy

FlowState is a local desktop timer. It does not collect, transmit, or sell personal data.

- No accounts, telemetry, analytics, crash reporting, advertising, or tracking.
- Settings, the current timer, and session history are stored only in the app's local data folder on your computer.
- The desktop app makes no network requests.
- Uninstalling FlowState does not delete your local settings or history; remove the app's data folder if you want them erased.

The FlowState website is a static site hosted on GitHub Pages. GitHub may record standard web-server information such as IP addresses and user agents under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement). The site uses no cookies, analytics, or third-party fonts.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
