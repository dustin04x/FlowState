# FlowState Website Brief

## Mode

Persuade

## Audience and success

People who want a simple desktop focus timer should understand what FlowState does and reach the correct download quickly.

## Offer and proof

FlowState is a compact, local-first desktop focus timer for starting a focus session, taking a break, and returning to work. Use the actual app screenshots and the existing release downloads as proof. Explain that settings and activity stay on the device, with no account or sync service.

## Structure

Build the first viewport as the user-selected Desk sheet: one useful sheet sets the reading order, with the product offer, a real app image, and direct platform choices visible together. Continue the same clear information hierarchy below the fold; do not turn the page into a literal poster or a row of generic feature cards.

## Required content

- Describe the focus presets, adjustable duration, breaks, local history, and tray behavior accurately.
- Offer the available Windows, macOS, and Linux downloads with the existing v1.0.0 links.
- Warn that Windows and macOS packages are unsigned and macOS is not notarized.
- Link to the public source repository.

## Constraints

- Spell the product name `FlowState`.
- Preserve the existing logo and “Get in. Lock in. Get out.” tagline.
- Use only verified product claims and actual screenshots; do not invent testimonials, usage numbers, performance claims, or platform validation.
- Preserve existing release asset URLs and identifiers used for local data or application communication.
- Keep the site independent from the Electron renderer and use the existing FlowState identity.
