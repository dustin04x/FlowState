# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: build the marketing site as static HTML, CSS, and JavaScript in a dedicated `website/` directory, separate from the Electron renderer and deployable with GitHub Pages.

## Users

People who want a simple desktop focus timer while working or studying.

## Product Purpose

FlowState helps people start a focus session, take a break, and return to work without adding a larger productivity system.

## Positioning

A compact, local-first desktop timer with focus and break sequencing, session history, and tray controls. Settings and activity stay on the device; there is no account or sync service.

## Operating Context

People use FlowState during focused work on a desktop. The compact window can stay above other windows or hide to the system tray while a session continues.

## Capabilities and Constraints

- Focus presets are 25, 45, and 60 minutes, with an adjustable focus duration.
- Short and long breaks, daily focus goals, and automatic session sequencing are configurable.
- Activity includes daily goal progress, a seven-day view, total focus time, completed sessions, and a current streak.
- Settings and activity history are stored locally; no network service is used.
- Windows, macOS, and Linux packages are available. Windows and macOS packages are unsigned; macOS is not notarized. Packaged behavior outside Windows has not been verified on physical systems.

## Brand Commitments

- Use the product name `FlowState`.
- Preserve the existing FlowState logo mark and the tagline “Get in. Lock in. Get out.”

## Evidence on Hand

- `README.md` documents product features, install instructions, and release links.
- `docs/assets/` contains screenshots of the actual Windows app, not mockups.
- Do not invent testimonials, customer counts, benchmarks, pricing, or unverified platform behavior.

## Product Principles

- Keep the focus timer useful without a broader productivity system.
- Keep settings and activity on the user's device.
- Let a session continue when the compact window is hidden.
- Describe platform support and signing status accurately.
